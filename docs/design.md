# 设计说明

本文记录三个阶段的设计取舍、关键公式与验证方式。所有算法都在 `src/` 中从零实现，只依赖 C++ 标准库。

## 1. FFT

### 1.1 为什么保留一个 O(N²) 的朴素 DFT

FFT 的结果无法靠"看起来像频谱"来判断对错。`dsp::dft()` 用 O(N²) 的直接求和实现同一数学定义，作为 FFT 的基准真值：在 N=1024 的随机复序列上，两者逐点误差在 1e-13 量级。

### 1.2 两条独立的 FFT 路径

- `fft()`：迭代式**时域抽取（DIT）**，先按位反转重排输入，再逐级做蝶形；
- `fftRecursiveDIF()`：递归式**频域抽取（DIF）**，先逐级蝶形拆分，最后得到位反转序输出。

两条路径的代码结构不同，但结果在 1e-14 量级内一致。这样即使某条路径里有隐性错误，也很难同时出现同样的错误。

### 1.3 其他验证

Parseval 定理、线性性质、时移对应频域乘旋转因子、实信号频谱的共轭对称，均写成了断言测试。FFT 与 IFFT 往返可还原。

### 1.4 实测加速比

见 README 表格。N=8192 时约 1230 倍，与理论量级 N/log₂N ≈ 630 的差异主要来自访存和常数因子，因此加速比随 N 增长而继续上升。

## 2. FIR / IIR 滤波

### 2.1 窗函数法设计 FIR

用 sinc 函数截断得到线性相位低通：截止频率决定主瓣位置，抽头数与窗型共同决定过渡带宽度和阻带衰减。四类窗的第一旁瓣实测分别为矩形 -20.9 dB、汉宁 -44.0 dB、汉明 -56.9 dB、布莱克曼 -78.0 dB。

系数归一化到 `sum(h) = 1`，保证直流增益为 1；抽头数取奇数，群延迟为整数个采样点。

### 2.2 IIR 双二阶节

二阶节形式 `y[n] = b0x[n] + b1x[n-1] + b2x[n-2] - a1y[n-1] - a2y[n-2]`，实现简单、便于级联。稳定性通过观察冲激响应判断：实测 200 点内衰减到 1e-25 以下。

FIR 与 IIR 的取舍：相同指标下 IIR 阶数低、算得快，但相位非线性；FIR 可以做到严格线性相位，代价是阶数高。

### 2.3 频谱泄漏

对非整数周期的正弦直接截断（矩形窗），能量会泄漏到相邻频点。同一信号改用汉明窗后，泄漏峰值从 -23.6 dB 降到 -43.7 dB，代价是主瓣变宽。

## 3. QPSK 链路

### 3.1 发射端

比特流按格雷映射成 QPSK 星座点，单位能量归一化为 `(±1±j)/√2`。上采样后经根升余弦（RRC）成形，滚降系数 β=0.35。收发两端各用一个 RRC，级联后等效为升余弦响应，在整数倍符号时刻无码间串扰。

RRC 的解析式在 `t = ±1/(4β)` 处是 0/0。实现时正负两侧都需要按极限值 `β/√2 · ((1+2/π)sin(π/(4β)) + (1-2/π)cos(π/(4β)))` 单独处理，只判正侧会在负侧产生 NaN 并污染整个滤波器。

### 3.2 信道与接收端

AWGN 由固定种子的线性同余发生器加 Box-Muller 变换生成，实部虚部各自服从 `N(0, σ²)`，同一 seed 结果完全可复现，便于回归比较。接收端匹配滤波后在符号时刻抽样，按实部、虚部符号做最近邻判决。

### 3.3 误码率

理论曲线为 `BER = ½·erfc(√(Eb/N0))`。每点发送 20 万比特，0–8 dB 实测与理论比值在 0.96–1.10 之间，8 dB 处实测 1.9e-4、理论 1.91e-4。

低信噪比处比值波动更大，原因是误码数足够多时统计稳定；而 8 dB 附近误码数只有约 40 个，相对误差本身就在 ±15% 量级。这也是为什么 `qpsk_demo` 允许用命令行参数增加比特数。
